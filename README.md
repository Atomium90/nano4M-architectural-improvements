# nano4M-architectural-improvements

This repository contains our COM-304 project on architectural improvements for the nano4M Transformer model.

We implement and evaluate several modifications:
- Rotary Positional Embeddings (RoPE) and alternative positional encodings
- SwiGLU feed-forward layers
- Improved weight initialization strategies
- Depth variation
- Residual-path scaling
